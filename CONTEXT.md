# GitLab extension

This context describes how OpenChamber users connect local repositories to GitLab for issue and merge request workflows.

## Language

**Local repository**:
A repository opened as a workspace in OpenChamber. It may be linked to a GitLab project.
_Avoid_: Project, when referring to the local workspace

**GitLab project**:
A repository and its related issues and merge requests on a GitLab instance.
_Avoid_: Local project

**GitLab connection**:
A user's authorized relationship with one GitLab account on one GitLab.com or self-managed instance.
_Avoid_: Project, server
